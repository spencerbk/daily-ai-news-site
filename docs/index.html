OpenAI reasoning model cracks Erdős's 80-year-old unit distance problem

Summary: An OpenAI general-purpose reasoning model produced a counterexample to Paul Erdős's 1946 planar unit distance conjecture, overturning a near-linear growth assumption that had stood for nearly 80 years.

Key Points:

  • The model constructed an infinite family of point arrangements yielding ~n^(1+δ) unit-distance pairs (δ ≈ 0.014, per Princeton's Will Sawin).
  • The proof leveraged advanced algebraic number theory — Golod–Shafarevich theory and infinite class field towers.
  • Verified by leading mathematicians including Tim Gowers and Thomas Bloom, including a previous skeptic of AI math claims.

Impact: First time an AI has independently resolved a core open problem in a mature mathematical field — a credible "Four Color Theorem moment" for AI-assisted research.
